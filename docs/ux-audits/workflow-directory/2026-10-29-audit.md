# UX audit: Workflow Directory items

**Date:** 2026-10-29
**Status:** Recommendations applied in this integration
**Evidence mode:** Source review, widget/server integration tests, and production Flutter route captures. The captures use controlled fixtures and Skia rendering; they do not exercise live cloud data.

## Scope

- Directory creation, listing, opening, rename, move, duplicate, trash and restore.
- Chat sidebar Directory, workflow tabs, tab naming, session restore and close.
- Workflow editor loading, saving, read-only state, exit confirmation, node picker and inspector.
- Connector tool discovery, access and Connection status, read/write sampling and inferred outputs.
- AI `readDirectory` and `readItem` paths for active, deleted and inaccessible items.
- Glossary and architecture/spec language for Workflow items and graph definitions.

## Findings

### UX-01: Closing a dirty workflow tab could discard edits without warning

- **Severity:** P1
- **Confidence:** High
- **Evidence:** The editor guarded its Back action, but the sidebar tab close path removed the tab directly. The close button now checks editor state and uses the shared discard dialog: `apps/auravibes_app/lib/features/browser/screens/browser_panel.dart:1377-1399`.
- **Recommendation:** Apply the same unsaved-change confirmation to the tab close button.
- **Status:** Fixed.
- **Verification:** `browser_panel_layout_test.dart` edits workflow metadata, keeps the tab when the user chooses “Keep editing”, then closes after confirmed discard.

### UX-02: AI could not select a Workflow as current workspace context

- **Severity:** P1
- **Confidence:** High
- **Evidence:** Context validation mapped folders and files explicitly, then treated every other item as a table. Workflow now resolves through the same visibility check and rejects record scopes: `apps/auravibes_server/lib/src/features/workspace_context/workspace_context_store.dart:293-315`.
- **Recommendation:** Validate Workflow selections as active workspace resources before allowing `readItem`.
- **Status:** Fixed.
- **Verification:** `workspace_conversation_commands_test.dart` searches by path/name, selects and reads an active Workflow, then confirms deleted Workflow reads fail and searches omit it.

### UX-03: Connector tool choices needed clearer grouping and requirements

- **Severity:** P2
- **Confidence:** High; source review and rendered compact/expanded captures.
- **Evidence:** Picker searches connector, tool title, description and stable ID; Connector tools group by Connector. Each entry shows operation type, workspace tool access and Connection state: `apps/auravibes_app/lib/features/workflows/widgets/workflow_node_picker.dart:185-200,404-503,521-575`. Captures show search results grouped under Brave Search, with read-operation, workspace-access and connection labels at 466×678 and 1280×800.
- **Recommendation:** Keep tools selectable without a Connection, but label whether the operation reads or writes and whether access or a Connection is missing.
- **Status:** Applied.
- **Verification:** Production route capture verifies Connector grouping, search, descriptions, operation type, missing workspace access and missing Connection. Automated picker tests cover selecting Connector tools; access and connected states have source-level coverage but no separate screenshot.

### UX-04: Connection lookup errors left sample controls without recovery

- **Severity:** P2
- **Confidence:** High; source review and retry widget test.
- **Evidence:** A failed Connection lookup disabled read sampling. The error now offers Retry and invalidates the Connection provider: `apps/auravibes_app/lib/features/workflows/widgets/workflow_connector_tool_sample.dart:128-138,253-275`.
- **Recommendation:** Preserve inputs and provide a direct retry action for recoverable lookup failures.
- **Status:** Fixed.
- **Verification:** `workflow_connector_tool_sample_widget_test.dart` injects a Connection lookup error, retries, and confirms the refreshed Connection. Automated checks cover shape-only read samples, write-sample non-execution and output inference.

### UX-05: Directory lifecycle and editor states

- **Severity:** No further issue found in source review.
- **Confidence:** High; source review and rendered compact/expanded captures.
- **Evidence:** Create uses the current folder and opens the saved item. Directory lists and opens Workflow items with the same item actions; chat tabs restore their stable item identity. The editor exposes read-only state and load retry, and inspector labels trashed nested workflows as unavailable. See `apps/auravibes_app/lib/features/workspaces/screens/workspace_items_screen.dart:685-740`, `apps/auravibes_app/lib/features/browser/screens/browser_panel.dart:1302-1352,1440-1500`, and `apps/auravibes_app/lib/features/workflows/widgets/workflow_inspector_panel.dart:29-105`.
- **Recommendation:** Keep Directory as the single lifecycle surface. Preserve stable references when duplicating and show unavailable nested steps until restored or repaired.
- **Status:** Applied.
- **Verification:** Local/cloud repository checks cover listing, save, move, duplicate, trash and restore. Widget checks cover workflow tab naming, read-only behavior, close and session restore. Captures show the Directory item and editor in compact and expanded layouts.

## Verification scenarios

1. Create a Workflow in a nested folder; confirm it opens, saves and remains in that folder after reload.
2. Move, duplicate, trash and restore a Workflow. Confirm copies get new IDs and keep Connector/tool and nested Workflow IDs.
3. Trash a referenced nested Workflow. Confirm its parent keeps the target ID and shows it unavailable; restore it and confirm the warning clears.
4. Open a Workflow from Directory and chat tabs. Confirm tab title, restored selection, close behavior and dirty-edit confirmation.
5. Search Connector tools by Connector, title and description. Confirm operation, access and Connection labels before selection.
6. Sample a read tool with temporary inputs; sample a write tool from pasted JSON only. Confirm raw values never persist and inferred ports merge optional fields/type conflicts.
7. Use AI path/name search and item read for active, deleted and unauthorized Workflows. Confirm only active resources visible to the current workspace member are returned.
